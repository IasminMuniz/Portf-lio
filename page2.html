Automação de Limpeza de Dados (Python)

Script utilizando Pandas para tratar valores nulos e padronizar colunas antes da importação para o Power BI.


import pandas as pd

# Carregar dados
df = pd.read_csv('vendas_brutas.csv')

# Preencher valores nulos
df['faturamento'].fillna(0, inplace=True)

# Padronizar nomes das colunas
df.columns = df.columns.str.lower().str.replace(' ', '_')

# Exportar base limpa
df.to_csv('vendas_limpas.csv', index=False)
print("Dados limpos com sucesso!")

Consulta de Faturamento por Cliente (SQL)

Query utilizada no banco de dados para criar a view consumida pelo dashboard de vendas.


SELECT 
    c.nome_cliente,
    COUNT(v.id_venda) as total_pedidos,
    SUM(v.valor_total) as faturamento
FROM clientes c
INNER JOIN vendas v ON c.id_cliente = v.id_cliente
WHERE YEAR(v.data_venda) = 2023
GROUP BY c.nome_cliente
ORDER BY faturamento DESC;
